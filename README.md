# ほしふるギルド

星のかけらで仲間を呼ぶ、ひとり用のソシャゲ風RPG（サーバーなし・課金なし）。

▶ https://nusag1.github.io/hoshifuru-guild/

## できること
- **ガチャ（星の召喚）**：★1〜★3 の12キャラ。天井・提供割合の表示あり。ゲーム内通貨だけで引ける
- **育成**：ゴールドでレベルアップ、同じキャラが出たら限界突破
- **編成**：3人パーティ、リーダーがホームに登場
- **コマンドバトル**：こうげき／スキル／ぼうぎょ、属性の三すくみ、オート・2倍速
- **クエスト**：第1章「はじまりの草原」、第2章「ほしぞらの洞窟」（各10ステージ＋ボス）
- **毎日の要素**：ログインボーナス（7日周期）、デイリーミッション、スタミナ

## 特長
- キャラ・敵はすべてオリジナルのドット絵（体・髪・アクセサリー・武器のパーツを組み合わせてコードで描画）
- データは端末に保存。オフラインでも遊べる（PWA）
